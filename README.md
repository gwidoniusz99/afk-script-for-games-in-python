# afk-script-for-games-in-python
### The game will never kick you out again when you are afk

### The script should work in any version of python, the version I tested it on is python 3.10.6

## how it works:
the script clicks the buttons for you and moves the character in a random direction

## How to use:
1. download and install any version of python
2. download the afk.py , requirements.txt and start.bat and place them in one folder
3. run start.bat , switch to game window and you're done!

### when you want to stop the script just close the open cmd window or switch to it and use ctrl + c
### when you want to run the script use start.bat

### games I tested it on: 
Minecraft, Roblox
